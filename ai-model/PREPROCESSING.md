# 이미지 전처리 규격 (팀 공통 규칙)

1학년 및 팀원들이 이미지를 모아올 때 아래 규칙을 지켜주세요.
학습 코드(`train.py`)와 추론 코드(`predict.py`)는 이 규격을 그대로 따름.

## 1. 입력 크기
- **224 x 224 px** 로 통일 (리사이즈는 코드에서 자동 처리하므로 원본은 정사각형일 필요 없음)

## 2. 색상
- RGB 3채널 (흑백/투명 배경 PNG는 RGB로 변환 후 사용)

## 3. 정규화
- ImageNet mean/std 기준 사용 (pretrained 모델과 호환)
  - mean: `[0.485, 0.456, 0.406]`
  - std: `[0.229, 0.224, 0.225]`

## 4. 폴더 구조 (ImageFolder 형식)
```
data/processed/
├── glass/
│   ├── img001.jpg
│   └── ...
├── can/
├── plastic/
└── ...
```
클래스별로 하위 폴더를 나눠서 저장 (파일명은 자유, 폴더명이 라벨)

## 5. 원본 이미지 수집 기준 (촬영/선정 시)
- 각도: 정면 / 측면 / 위에서 내려다본 각도를 고르게 섞기
- 조명: 밝은 환경, 어두운 환경 모두 포함
- 배경: 단색 배경 + 실제 생활 환경 배경 섞기
- 상태: 뚜껑 유무, 라벨 유무, 색깔/투명 유리병 등 다양하게

## 6. 데이터 증강 (학습 시 자동 적용, train.py 참고)
- 현재 적용: 좌우 반전 (RandomHorizontalFlip)
